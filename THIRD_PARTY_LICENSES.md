# Third-party licenses

AURA Split TR (`aurasplit.exe`) is licensed under GPL-3.0-or-later (see [LICENSE](LICENSE) and [NOTICE](NOTICE)).
The Windows binary statically links the Go modules listed below and embeds one
prebuilt Windows binary (the Wintun DLL). Since the build uses the sing-box tag
`with_external_windivert`, the WinDivert kernel driver is **not** embedded (the
WinDivert Go code is linked but never used; it would only read the driver from
disk). The WinDivert entries below are kept for builds without that tag.

**How this list was produced** (re-run before every release; the list changes when `go.mod` changes):

```powershell
$env:GOOS="windows"; $env:GOARCH="amd64"; $env:CGO_ENABLED="0"
go list -deps -tags with_gvisor,with_wireguard,with_external_windivert -f '{{if .Module}}{{.Module.Path}} {{.Module.Version}}{{end}}' ./cmd/aurasplit | Sort-Object -Unique
```

(module versions updated 2026-11-22 after the dependency bump; license texts not re-read for the bumped versions). SPDX identifiers were assigned by reading each
license file; they are not machine-verified. This file is informational and is
